# Adapta Wizard - Official Releases

This repository contains official release builds for **Adapta Meetings**, an audio transcription and note-taking application for productivity.

> **Note:** This is a releases-only repository. The source code is maintained separately.

## Download

Download the latest version for your platform:

### macOS
- **DMG Installer**: `adapta-meetings-{version}.dmg`
- **Architecture**: Apple Silicon (arm64) and Intel (x64) supported

### Windows
- **Installer**: `adapta-meetings-{version}-setup.exe`
- **Architecture**: x64

### Linux
- **AppImage**: `adapta-meetings-{version}.AppImage`
- **Debian Package**: `adapta-meetings-{version}.deb`

## Installation

### macOS
1. Download the `.dmg` file from the [latest release](https://github.com/adapta-school/adapta-meetings-releases/releases/latest)
2. Open the DMG and drag Adapta Meetings to your Applications folder
3. On first launch, you may need to right-click and select "Open" to bypass Gatekeeper

### Windows
1. Download the `.exe` installer from the [latest release](https://github.com/adapta-school/adapta-meetings-releases/releases/latest)
2. Run the installer and follow the setup wizard
3. Launch Adapta Meetings from your Start Menu or Desktop shortcut

### Linux
**AppImage:**
1. Download the `.AppImage` file
2. Make it executable: `chmod +x adapta-meetings-{version}.AppImage`
3. Run it: `./adapta-meetings-{version}.AppImage`

**Debian/Ubuntu:**
1. Download the `.deb` file
2. Install: `sudo dpkg -i adapta-meetings-{version}.deb`
3. Fix dependencies if needed: `sudo apt-get install -f`

## Auto-Updates

Adapta Meetings includes automatic update functionality. When a new version is released:

1. The app will detect the update automatically on launch
2. Download the update in the background
3. Prompt you to restart when ready
4. Updates can be installed immediately or postponed

You can check for updates manually through the app menu.

## System Requirements

### macOS
- macOS 10.13 (High Sierra) or later
- Apple Silicon or Intel processor

### Windows
- Windows 10 or later
- 64-bit processor

### Linux
- Modern Linux distribution (Ubuntu 18.04+, Fedora 30+, etc.)
- 64-bit processor
